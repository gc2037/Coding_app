# Code Studio

A Next.js coding workspace with Monaco, GitHub Models AI chat, and Piston code execution.

## Setup

```bash
npm install
npm run dev
```

Set `GITHUB_TOKEN` to a GitHub PAT with Models access.

## Features

- Monaco editor
- JavaScript, TypeScript, Python, Java, C++, C#, Go, Rust, PHP, Ruby, Swift, Kotlin, HTML, CSS, and SQL
- GitHub Models chat using `openai/gpt-4o-mini`
- Piston-backed execution for supported runtimes
- Responsive three-panel interface
